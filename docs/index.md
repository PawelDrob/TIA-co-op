# Folders

* [ADRs](adr/index.md) - Decisions a reader of the code would otherwise wonder about, one short record each.
* [Agent](agent/index.md) - Guides an agent reads while working on a TIA project: SIMATIC SD for PLC blocks, SimaticML through Openness for WinCC Comfort screens, the screen objects, what Openness can do.
* [Agent skills](agents/index.md) - The config of the engineering skills for changing this repo: issue tracker, triage labels, domain docs. Not the guides, which are in Agent.
* [Dev](dev/index.md) - How the tools are built, for people changing them: overview, one page per tool, decisions, known issues, testing, conventions, roadmap.
* [User](user/index.md) - Start here: the [README](../README.md) of the repository and of each tool. These pages hold what is too long for a README: first setup, what the agent status views show, the development dashboard.
